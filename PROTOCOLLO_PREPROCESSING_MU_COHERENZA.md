**Protocollo Operativo SYNC: Preprocessing -> Estrazione MU (OTBioLab+) -> Coerenza**

**1) Scopo**

Questo documento descrive \*\*solo\*\* la pipeline SYNC, coerente con:

• allineamento_eeg_emg_sync.m

• coerenza/coerenza_motoria_source_batch.m (versione sync)

Obiettivi:

1 allineamento temporale EEG/EMG robusto con trigger;

2 creazione file OTB con soli segmenti di movimento;

3 estrazione Motor Units (MU) in OTBioLab+;

4 calcolo coerenza cortico-sinergica con le stesse regole della pipeline sync.

**2) Input/Output SYNC**

Input run:

• EEG .mff

• EMG .otb+

Output principali (per run):

• \*\_aligned_otb.mff

• \*\_aligned_otb_events.csv

• report.json

• \*\_movement_only.otb+

• \*\_movement_segments.csv

Output batch sync:

• allineamento: batch_otb_mff/output_matlab_sync

• coerenza: coerenza/coerenza_motoria_source_sync

**3) Logica trigger SYNC (allineamento)**

Regole operative:

1 \*\*Trial gating\*\* su DIN4/DIN5 (DIN1 non e' gate di trial validita').

2 Sequenza logica trial: start < keyboard < beep < end e end < keyboard successivo.

3 \*\*Pulizia trigger\*\* su AUX (rimozione edge troppo ravvicinati) con controllo di plausibilita' numerica.

4 \*\*Gap minimo keyboard->beep = 50 ms\*\* per evitare coppie quasi simultanee.

5 \*\*DIN1 denso (onda sync)\*\*: usato solo per rifinitura del fit affine (a,b) dopo il fit principale DIN4/DIN5.

6 Guardrail qualità fit: run bloccato se fit instabile (es. drift/mad fuori soglia).

**4) Segmentazione movimento per OTB**

Il file \*\_movement_only.otb+ viene creato automaticamente nella sync.

Regole segmentazione:

• primaria: beep -> start

• fallback automatico: beep -> end se start non e' successivo a beep

Tracciabilita':

• \*\_movement_segments.csv: trial, tempi MFF, tempi OTB, sample, durata

• report.json: movement_only.rule_used, n_segments, duration_s, eventuale reason

**5) Estrazione MU in OTBioLab+ (sync)**

Workflow consigliato:

1 aprire \*\_movement_only.otb+;

2 selezionare griglia/canali del muscolo target;

3 Processing > Decomposition > Decomponi;

4 editing manuale IPT/IDR;

5 salvare solo MU approvate;

6 esportare firing samples e tracce MU (.mat/.csv).

Nota operativa:

• preferire blocchi grouped ~20-100 s per stabilita' di decomposizione.

**6) QC MU (raccomandato)**

Accettazione MU:

1 PNR >= 30 dB (criterio forte);

2 spike train fisiologicamente plausibile;

3 rimozione MU con pattern artefattuali dopo editing;

4 registrare MU accettate/scartate per run.

**7) Coerenza SYNC: parametri vincolanti**

La coerenza sync deve restare coerente col codice:

1 trial da eventi ricostruiti: beep -> first start before next beep;

2 durata minima trial: 0.50 s;

3 preprocessing EMG: band-pass 20-450 Hz, notch 50 Hz + armoniche, rettifica, low-pass 10 Hz;

4 riallineamento EMG su asse EEG con (a,b) del report sync;

5 NMF sinergie: maxK=6, target VAF globale >= 0.90, VAF minimo canale >= 0.75;

6 coerenza: downsample interno ~250 Hz, finestra ~0.8 s, overlap 50%, nfft >= 512;

7 bande: beta 13-30 Hz, sotto-bande 13-20 e 20-30 Hz.

**8) Source-space in SYNC**

Ordine di priorita':

1 usare sources_eeg.mat se disponibile (source_net);

2 fallback scalp-proxy se source assente/non valido;

3 salvare sempre mode e stato source in summary/report.

**9) Checklist SYNC run-by-run**

1 report.json presente e senza errori;

2 logical.enabled = true;

3 movement_only.enabled = true;

4 movement_segments.csv presente;

5 trial_info.csv presente in output coerenza sync;

6 verificare eventuale beep_to_end_fallback nei run finali.

**10) Methods (paper-ready, versione sync)**

**10.1 Alignment and synchronization refinement**

EEG and HD-EMG were aligned through trigger-based affine mapping. Trial validity was constrained by DIN4/DIN5 temporal order, while DIN1 was excluded from trial acceptance. In the sync pipeline, dense DIN1 trains were optionally used only to refine affine clock-drift parameters after the DIN4/DIN5 fit.

**10.2 Trigger cleaning and trial enforcement**

Auxiliary trigger streams underwent minimum-gap cleaning and count plausibility checks before mapping. Valid trials were reconstructed under strict logical order (start < keyboard < beep < end) with a minimum keyboard-beep separation of 50 ms.

**10.3 Movement-only HD-EMG export**

Movement-only OTB files were generated by concatenating valid trial windows. Primary windows were defined as beep-to-start; when start did not follow beep, beep-to-end fallback was applied and explicitly logged.

**10.4 MU decomposition**

MU decomposition was performed in OTBioLab+ (Decomponi), followed by manual review and approval. Firing samples and MU tracks were exported for downstream analyses. Quality control prioritized high-confidence units (recommended PNR threshold >= 30 dB).

**10.5 Cortico-synergy coherence**

Coherence was computed on beep->start trials (minimum 0.5 s), after EMG envelope preprocessing and EMG-to-EEG temporal remapping with run-specific affine parameters. NMF extracted up to six synergies with VAF constraints; beta-band coupling (13-30 Hz) and related metrics (z-coherence, lag-optimized beta coherence, PSI, ROI state-dependent contrasts) were computed with fixed spectral settings.
